# Visualization

The simulator has three ways to watch a run. They all show the same
simulation; pick whichever fits.

| Tool | Start it with | Output |
|---|---|---|
| Browser app (`server.py` + `static/`) | `py server.py` | Live page: pick a problem, load or generate a plan, schedule anomalies, run, play back hour by hour on the grid |
| Grid animation (`visualizer.py`) | `py visualizer.py --problem p01 --save run_p01.gif` | Animated GIF/MP4 (or a window with `--show`) of the grid map; needs matplotlib |
| Run map (`run_map.py`) | automatic after every `py main.py ...` run | `run_maps\<problem>_map.html` with replan tracking |

> `run_map.py` was called `visualizer.py` on the `New_anomaly_changes` branch
> (visualizationtest3). It was renamed so the grid animation could keep the
> name `visualizer.py`. Its contents and behavior are unchanged.

## Run map (`run_map.py`)

This is the `New_anomaly_changes` branch of the PDDL Anomaly Replanning
Simulator (external `--plan` workflow, Windows Fast Downward included) plus an
automatic interactive run map generated after every simulation.

### Windows usage (PowerShell, in this folder)
    py check_setup.py
    py main.py --problem p01 --plan plans\p01.plan
    py main.py --problem p01 --plan plans\p01.plan --anomaly-id 1 --step-id 2 --anomaly-args l1 l3

The map is written to `run_maps\<problem>_map.html` and opens in the default
browser. Flags: `--no-map` skips it, `--map-file PATH` chooses the location.

Rebuild a map from a saved log (UTF-8 or PowerShell UTF-16 both work):

    py main.py --problem p01 --plan plans\p01.plan --anomaly-id 1 --step-id 2 --anomaly-args l1 l3 > run.txt
    py run_map.py run.txt fast-downward-24.06.1\trucks\p01.pddl

### Reading the map
Circles are locations, lines are roads. Closed roads turn red and dashed. The
blue rectangle is the truck (red if broken down). Packages are yellow waiting,
blue aboard, green delivered.

### Replan tracking
- A banner and an orange marker on the timeline slider show every replan; the
  "Jump to Replan #N" buttons go straight to it.
- The sidebar lists the active plan with finished actions ticked and the next
  action highlighted.
- At a replan, "What changed in the plan" compares the unexecuted part of the
  old plan with the new plan: kept, removed (red) and added (green) actions.

### How the pieces fit
The PDDL problem file, the plan file and the simulator run stay separate.
`run_map.py` combines the problem file (static world) with the simulator
output (timeline); it can also be run later on a saved log.

## Grid animation (`visualizer.py`)

Runs the simulator in-process and reads `Simulator.state_history` directly
(no subprocess, no log parsing). 1 grid cell = 1 mile, roads are labeled
`distance @ speed = travel time`, and trucks move along roads one frame per
hour.

    py visualizer.py --problem p01 --no-anomalies --save run_p01.gif
    py visualizer.py --problem p01 --anomaly road_closure:3:l2:l3 --show
    py visualizer.py --problem p01 --anomaly-chance 0.3 --seed 42 --save run.gif

The plan is generated by Fast Downward.

## Browser app (`server.py`)

    py server.py

Opens `http://127.0.0.1:8765/`. The map appears as soon as a problem is
selected (no planner needed). Choose **Generate** (Fast Downward) or **Load plan
file** (from `plans\`), add scheduled anomalies and/or a random anomaly chance,
then Run. Problems can be loaded from a `.pddl` file; original-format files get
road distances, speeds and a grid added automatically.

## Testing different PDDL problems
`--problem pNN` loads `fast-downward-24.06.1\trucks\pNN.pddl` (plus `domain.pddl`).
Without `--plan` the plan is generated; to use a pre-made plan, pass `--plan`:

    py main.py --problem p12 --save-plan
    py main.py --problem p12 --plan plans\p12.plan --anomaly-id 1 --step-id 4 --anomaly-args l1 l2

`py tools\make_plans.py` regenerates every file in `plans\` (needed after
`tools\upgrade_problems.py` changes the problems).

Your own problem file: save it in `fast-downward-24.06.1\trucks\` as `mytest.pddl`
and use `--problem mytest`, or load it in the browser app.
