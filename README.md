# PDDL Anomaly Replanning Simulator

Research project for extending an existing PDDL-based logistics simulator built on Fast Downward.

## Main Files

- `main.py` — entry point
- `gui.py` — graphical interface
- `simulator.py` — simulation engine
- `planner.py` — Fast Downward interface
- `anomalies.py` — anomaly definitions
- `case_library.py` — case-based reasoning
- `state.py` — world-state representation
- `pddl_parser.py` — PDDL parser
- `pddl_writer.py` — PDDL generation
